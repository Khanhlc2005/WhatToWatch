Pill-shaped tags for genres. The same pill works as a toggle in filters and as a suggested prompt in chat.

- Props: `selected` (makes it a toggle with `aria-pressed`; on = `marquee` fill plus a check), `onClick` (makes it a plain button, used for chat suggestions), `children`.
- A static genre chip has a `surface-300` fill and no border. A clickable chip has a `line-strong` border.
